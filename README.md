# ?? Salon Management System

A modern PHP (MVC) web application for beauty salon booking and service management.

## ?? Features
- Client portal with online appointment booking
- Admin dashboard for services and client management
- Multi-language support (EN, RU, ET)

## ?? Tech Stack
- PHP, MySQL, HTML5, CSS3, JavaScript

## ?? Quick Start
1. Clone or copy project files into your web server directory (xampp/htdocs/salon)
2. Import the database schema from the config directory
3. Configure connection details in config/db.php`n4. Open http://localhost/salon in your browser
